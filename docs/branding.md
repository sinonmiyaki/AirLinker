# 로고와 아이콘

코발트색 바탕에 오른쪽 위로 이륙하는 흰 비행기를 배치했습니다. 작은 작업 표시줄 아이콘에서도 알아보기 쉽도록 하나의 실루엣으로 구성했습니다.

- 원본: [앱 로고 SVG](../airlinker/assets/airlinker.svg), [단색 심볼 SVG](../airlinker/assets/mark.svg)
- 적용: 앱·설정 창, 작업 표시줄, EXE·설치 프로그램·바로가기, 설치 마법사, 대기 애니메이션, README
- 형식: 16–256px PNG/ICO, 512px PNG, 설치 마법사용 BMP
- 재생성: `python scripts/build-icons.py` (PySide6 필요)

외부 에셋 없이 제작했으며 프로젝트의 GPL-3.0-or-later로 제공합니다. 라이선스 원문과 제3자 고지는 축약하지 않습니다.
