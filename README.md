# AirLinker

**iPhone·iPad·Mac 화면을 Windows로.** 유료 미러링 앱 대신 만든 무료 오픈소스 AirPlay 수신기입니다.

[Windows 설치 파일 · 약 79MB](https://github.com/sinonmiyaki/AirLinker/releases/download/v0.1.3/AirLinker-Setup-0.1.3-x64.exe) · [Release](https://github.com/sinonmiyaki/AirLinker/releases/tag/v0.1.3)

Windows 10/11 x64용입니다. 설치는 EXE 하나면 됩니다. Source ZIP은 설치에 필요하지 않습니다.

## 사용하기

1. Windows와 Apple 기기를 같은 네트워크에 연결합니다.
2. AirLinker를 실행합니다.
3. 기기의 **제어 센터 → 화면 미러링 → AirLinker Windows**를 선택합니다.

영상이 나오면 설정 버튼이 숨습니다. **화면 상단 중앙에 마우스를 올리면** 다시 내려옵니다.

Preview 버전입니다. Windows 자동 검증을 통과했으며, Apple 실기기 호환성은 추가 확인이 필요합니다. DRM 보호 영상은 지원하지 않습니다.
